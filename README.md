# virtual-machine-jvm
Virtual Machine (JVM) — студенческий проект НИЯУ МИФИ: язык Egg, компилятор и виртуальная машина.

- Спецификация языка: [docs/egg-spec-v0.1.md](docs/egg-spec-v0.1.md)
- Публичный интерфейс лексера: [include/egg/lexer.h](include/egg/lexer.h)
- Как работать с git и PR (шпаргалка): [CONTRIBUTING.md](CONTRIBUTING.md)
- Доска задач: [GitHub Project](https://github.com/users/alex-dnd/projects/1)

Структура (договорённость для лексера): `include/egg/` — публичные заголовки, `src/` — реализация, `tests/` — тесты.

## Реализация лексера

`Lexer` хранит исходный текст. Каждый вызов `tokenize()` создаёт отдельный
`detail::Scanner` с состоянием одного прохода. Его методы распределены по файлам:

| Файл в `src/lexer/` | Ответственность | Участник |
|---|---|---|
| `lexer.cpp` | Конструктор и публичный `tokenize()` | Глеб |
| `scanner.h` | Внутреннее объявление класса и общие договорённости | Совместно |
| `scanner.cpp` | Главный цикл, добавление токенов, диагностика | Глеб |
| `trivia.cpp` | UTF-8, BOM, позиции, пробелы, комментарии | Нина |
| `tokens.cpp` | Идентификаторы, ключевые слова, числа, знаки | Димка Петрик |
| `literals.cpp` | Символьные и текстовые литералы, escape | Леша |

`scanner.h` — внутренний заголовок; пользователи библиотеки подключают
`egg/lexer.h`. Небольшие операции чтения позиции и продвижения по ASCII
определены непосредственно в классе. Все `.cpp` компилируются через CMake.

Методы `scan_*` при успехе добавляют один завершённый токен и оставляют позицию
сразу после него. `skip_trivia()` пропускает разделители без добавления токенов.
При ошибке метод записывает первую диагностику через `fail()` и возвращает
`false`; главный цикл останавливается без частичного токена и без EOF.
При успехе главный цикл добавляет ровно один EOF.

Каждый участник добавляет проверки своей части в соответствующий файл в
`tests/`; `test_spec.cpp` предназначен для проверок спецификации в целом.
Заглушки в `tokens.cpp` и `literals.cpp` ещё предстоит реализовать.

Для форматирования реализации используйте общий `.clang-format`:

```sh
clang-format -i src/lexer/*.cpp src/lexer/scanner.h
```
