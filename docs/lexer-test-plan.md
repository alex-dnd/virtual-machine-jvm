# Тест-план лексера

| № | Что проверяем | Вход | Ожидание | Источник |
|---|---|---|---|---|
| 1 | Пустой файл | `""` | Один EOF, ошибок нет | `lexer.h`, `LexResult` |
| 2 | Буква после числа | `12abc` | `InvalidIntegerSuffix`, токенов нет | spec §1 |
| 3 | Русская буква | `Я` | Позиция корректна: 2 байта, 1 колонка | spec §1 |
| 4 | Табуляция | `\tx` | Колонка следующего токена корректна | spec §1 |
| 5 | CRLF | `a\r\nb` | Строка увеличивается корректно | spec §1 |
| 6 | BOM в начале | BOM + `int` | BOM не создаёт лишний токен | spec §1 |
| 7 | Двойной минус | `int x = 1--2;` | Два отдельных токена `Minus` | spec §9 |
| 8 | Несколько символов в char | `char c = 'ab';` | `InvalidCharacterLength` | spec §9 |
| 9 | Русская буква в char | `char c = 'Я';` | `NonAsciiInLiteral` | spec §9 |
| 10 | Управляющий символ | `char c = '\x7F';` | `CharLiteral` со значением 127 | spec §9 |
| 11 | Строка с кириллицей | `vector<char> s = "Привет";` | `NonAsciiInLiteral` | spec §9 |
| 12 | Программа с комментариями | несколько строк | Корректные токены и EOF | spec §1, §9 |
| 13 | BOM внутри литерала | кавычка + BOM + кавычка | `UnexpectedBom`, диапазон охватывает 3 байта | `lexer.h`, `LexErrorCode` |
| 14 | Недопустимый символ внутри escape | после `\`, `\x` или `\x4`: LF, CR, BOM, битый UTF-8, не-ASCII, управляющий ASCII | Соответствующий код ошибки и диапазон символа; предыдущие токены сохранены, EOF отсутствует | `lexer.h`, `LexErrorCode`, `LexResult` |
| 15 | Незавершённые escape | `\` перед EOF; `\x` или `\x4` перед EOF | `InvalidEscape` или `InvalidHexEscape` соответственно | `lexer.h`, `LexErrorCode` |
